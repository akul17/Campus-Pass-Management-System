# Campus Pass Management System

A web-based Campus / Transport Pass Management System built with HTML, CSS, and JavaScript.

## Features

- **Authentication / Role-based Login:** Pass Holder / Commuter and Administrator access.
- **Commuter Dashboard:** View active passes, apply for a new pass, and update transit routes.
- **Pass Creation & Payment:** Multi-step or integrated pass application with payment simulation.
- **Admin Management:**
  - Active passes overview
  - Expiring / Expired passes management
  - Pass approval workflow
- **Digital Pass & QR Verification:** Pass layout with photo and QR code verification.

## Project Structure

- `index.html` - Login / Entry page
- `dashboard.html` - User dashboard
- `new-pass.html` - New pass registration form
- `payment.html` - Payment handling
- `view-pass.html` - View issued digital campus pass
- `update-route.html` - Route modification requests
- `admin-dashboard.html` - Admin portal overview
- `admin-active-passes.html` - Admin view for active passes
- `admin-approve-passes.html` - Admin pass approval queue
- `admin-expired-passes.html` - Admin view for expired passes
- `styles.css` - Application styling
